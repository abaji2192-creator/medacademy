# MedAcademy — Medical Staff Training & Assessment Platform

Tibbiyot muassasasi xodimlarini o'qitish, test qilish, baholash, sertifikatlash va monitoring qilish platformasi (MVP).

- **Frontend:** bitta sahifali ilova (`index.html`), GitHub Pages orqali joylashtirilgan
- **Backend:** Supabase (Auth + PostgreSQL + Row Level Security)
- **Rollar:** Super Admin, HR, Education Manager, Bo'lim boshlig'i, Instructor, Xodim
- **Demo rejim:** login sahifasidagi "Demo" bo'limi — ma'lumotlar faqat brauzerda saqlanadi

Birinchi ro'yxatdan o'tgan foydalanuvchi avtomatik Super Admin bo'ladi; keyingi xodimlar HR/Admin tasdig'idan keyin faollashadi.
